## Selected engineering

**[Resilient WebSocket Gateway](https://github.com/rhazem13/resilient-ws-gateway)**

Two TypeScript gateways share session state in Redis. Failure tests kill a connected instance, reconnect through a non-sticky proxy, and verify bounded event replay. The repository includes owner isolation, slow-reader tests, a runnable Docker demo, and measured local load results with explicit limits.
